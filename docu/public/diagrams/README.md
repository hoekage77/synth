# Diagram Images

This folder contains static diagram images for the documentation.

## Required Images

1. **system-architecture.png** - System overview diagram showing all layers
2. **data-flow.png** - Data flow sequence diagram  
3. **tool-execution.png** - Tool execution flow diagram

## How to Create Diagrams

### Option 1: Draw.io (Recommended)
1. Go to [draw.io](https://app.diagrams.net/)
2. Create your diagram
3. Export as PNG with resolution 800x600 or higher
4. Save to this folder

### Option 2: Excalidraw
1. Go to [excalidraw.com](https://excalidraw.com/)
2. Create your diagram
3. Export as PNG
4. Save to this folder

### Option 3: Any Diagram Tool
- Use any diagram tool you prefer
- Export as PNG format
- Ensure good resolution (800x600 minimum)
- Save to this folder

## Image Specifications

- **Format**: PNG (preferred) or SVG
- **Resolution**: Minimum 800x600 pixels
- **Style**: Clean, professional, consistent with documentation theme
- **Colors**: Use the project's color scheme if possible
